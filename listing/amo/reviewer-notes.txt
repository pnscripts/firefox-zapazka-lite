No build step, no minified or generated code: the uploaded zip is the extension folder as it is (source: https://github.com/pnscripts/firefox-zapazka-lite, tag v1.1.0).

What changed in 1.1.0: core.js gained contentRisk()/riskAt() (regular expressions plus the Luhn and ISO 7064 checks) that run on the text of a text area before it is stored in browser.storage.local, a refusal ledger (key "l:<hostname>": field name, reason code, count, time; never the text), and a page report. The content script answers the popup's "zapazka-report" message with the list of text areas on the page and the reason each is kept or refused. The background script sets the per-tab toolbar badge (browser.action.setBadgeText) from a "zapazka-badge" message sent by the top frame.

Host access (<all_urls>) is needed to see the text areas on the pages the user writes in. The content script reads text area values typed by the user and stores them, and nothing else, in storage.local; the extension makes no network requests, loads no remote code and declares data_collection_permissions "none". Private windows: incognito "not_allowed". Tests: make test (19), make lint, make firefox (headless Firefox, 12 steps).
